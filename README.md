# Weather App

A responsive weather application built as part of **The Odin Project** curriculum. It fetches real-time data from an external weather API and dynamically renders forecasts based on user search queries.

[Live Demo](https://00kamil00.github.io/Project-Weather-App/)

---

### Features

- Real-time weather lookup by city name
- Displays city name, temperature, conditions, and humidity
- Toggle between Celsius and Fahrenheit (°C / °F)
- Dynamic UI updates with loading state indicators

### Tech Stack

- JavaScript (ES6+, Async/Await, Fetch API)
- HTML5 & CSS3 (Flexbox / Grid)
- WeatherAPI
- Webpack
